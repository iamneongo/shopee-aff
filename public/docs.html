Giới thiệu

REST API cho hệ thống cashback Shopee affiliate: tạo affiliate link gắn theo từng user (để quy hoa hồng) và lấy báo cáo chuyển đổi. Mọi response là JSON với trường ok: true/false.

✅ Stateless — tạo link chỉ là ghép chuỗi qua endpoint chuyển hướng chính thức của Shopee (s.shopee.vn/an_redir). Không cần Chrome, không captcha, không proxy, không đăng nhập.

Kiến trúc

Tạo link:  client → POST /api/link → linkBuilder → chuỗi s.shopee.vn/an_redir
           (khi user click → Shopee tự gắn tracking + redirect tới sản phẩm)

Báo cáo:   client → GET /api/report → affiliate.shopee.vn/report/list (bằng cookie)

Link affiliate có dạng:

https://s.shopee.vn/an_redir?origin_link=<url SP>&affiliate_id=<id>&sub_id=<s1-s2-s3-s4-s5>

Khi user click, Shopee 301 tới trang sản phẩm và tự gắn utm_source=an_<affiliate_id>, utm_content=<sub_id>, utm_medium=affiliates → hoa hồng quy về đúng affiliate + user. Đây là cơ chế các network (AccessTrade/Involve Asia) vẫn dùng.

💡 origin_link nên là URL sản phẩm chuẩn (...-i.<shop>.<item> hoặc /product/<shop>/<item>). Link rút gọn (s.shopee.vn/xxx) được server tự resolve về URL chuẩn trước (nếu không sẽ mất tracking).

affiliate_id là ID tĩnh của tài khoản affiliate (công khai, nằm trong mọi link). Cấu hình phía server qua env SHOPEE_AFFILIATE_ID hoặc config.affiliateId; có thể override từng request bằng trường affiliateId trong body.

Cashback & SubIds

Shopee cho gắn tối đa 5 SubId vào mỗi link; khi có đơn, báo cáo trả lại đúng các SubId → dùng để quy đơn về từng user.

⚠️ SubId chỉ chấp nhận [a-zA-Z0-9], tối đa 40 ký tự — không dấu gạch dưới, không ký tự đặc biệt. Vi phạm → server trả 400 INVALID_SUBID trước khi tạo link.
SubIdÝ nghĩaVí dụ
subId1userId — người nhận cashback (truyền qua trường userId)u12345
subId2Nguồn / nền tảngweb, app
subId3Nhãn / chiến dịchcashback
subId4, subId5Tuỳ ý (mã đơn, click id…)—

Luồng cashback:

  1. User bấm "lấy link" → gọi POST /api/link kèm userId → link gắn subId1 = userId.
  2. User mua hàng qua link đó.
  3. Cron định kỳ gọi GET /api/report/by-subid?subIds=<userId> → ra đơn + hoa hồng → cộng cashback.
💡 Nên cache (userId, originalLink) → shortLink ở DB riêng — link Shopee là vĩnh viễn. (Thực ra link an_redir là tất định nên có thể tự dựng, nhưng cache vẫn giảm số lần gọi.)

Luồng 1 — Tạo link cashback (khi user bấm "lấy link")

Nên cache (userId, originalLink) → shortLink ở DB của bạn (link vĩnh viễn) để khỏi gọi lại.

async function getCashbackLink(userId, originalLink) {
  const cached = await db.links.findOne({ userId, originalLink });
  if (cached) return cached.shortLink;
  const r = await fetch(process.env.SHOPEE_API + "/api/link", {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": process.env.SHOPEE_API_KEY },
    body: JSON.stringify({ originalLink, userId }), // userId: chỉ [a-zA-Z0-9], ≤ 40 ký tự
  });
  const j = await r.json();
  if (!j.ok) throw new Error(`link fail ${j.code}: ${j.error}`);
  await db.links.insert({ userId, originalLink, shortLink: j.shortLink, at: Date.now() });
  return j.shortLink; // https://s.shopee.vn/an_redir?origin_link=...&affiliate_id=...&sub_id=userId-...
}

Luồng 2 — Đối soát + cashback + clawback (cron)

Dùng /api/conversions (đã chuẩn hoá: 1 dòng/order, có userId, status, commission VND, isFraud). Gợi ý cron: mỗi 1–2h lấy 3–7 ngày + mỗi ngày quét 30–45 ngày.

async function reconcile() {
  const j = await fetch(process.env.SHOPEE_API + "/api/conversions?days=30&size=100",
    { headers: { "x-api-key": process.env.SHOPEE_API_KEY } }).then(r => r.json());
  if (!j.ok) { alertAdmin(j.code, j.error); return; }  // NO_REPORT_COOKIE → cập nhật /cookie.html
  for (const c of j.conversions) {
    if (!c.matched) { await saveUnmatched(c); continue; }              // đơn rụng sub_id → chờ gán tay
    if (c.status === "CANCELLED" || c.status === "REFUNDED") {
      await clawback(c.orderSn);                                        // thu hồi nếu đã trả (P3)
    } else if (c.status === "COMPLETED" && !c.isFraud) {
      await creditCashback(c.orderSn, c.userId, c.commission);         // idempotent theo orderSn
    }
  }
}
💡 Chỉ trả cashback khi status==="COMPLETED" && !isFraud; CANCELLED/REFUNDED → thu hồi. orderSn làm khoá UNIQUE (không cộng trùng). Đơn matched:false → lưu "chờ gán", gán bằng POST /api/conversions/map.

Giám sát

Gọi GET /api/selfcheck hằng ngày (200 = khỏe, 503 = lỗi — tiện gắn UptimeRobot). Server cũng tự chạy mỗi 24h và báo Telegram khi cookie report hết hạn.

Cookie report & tần suất

Report đọc bằng cookie affiliate.shopee.vn (không bị chặn TLS/captcha như tạo link). Cookie sống ~1–2 tuần.

Cập nhật cookie
  1. Mở /cookie.html, nhập API key.
  2. Đăng nhập affiliate.shopee.vn → trang Báo cáo chuyển đổi → F12 → Network → request report/list → Request Headers → copy header Cookie.
  3. Dán vào ô Cookie → Lưu → Test.
✅ Khi cookie hết hạn (report lỗi 90309999) → server tự gửi cảnh báo Telegram/webhook nhắc vào /cookie.html.

Logic tạo link (/api/link)

Code: src/linkBuilder.js. Các bước:

  1. Nhận originalLink + userId/subIds + affiliateId (từ env/config).
  2. Chuẩn hoá link (resolveToCanonical): nếu là link rút gọn (s.shopee.vn/xxx) thì theo redirect (chỉ đọc header Location, không tải trang) để lấy URL sản phẩm chuẩn /product/<shop>/<item>. Lý do: an_redir chỉ gắn tracking đầy đủ khi origin_link là URL sản phẩm chuẩn; nếu để link rút gọn thì mất tracking.
  3. Ghép sub_id: subId1..subId5 nối bằng dấu - (bỏ đuôi rỗng), subId1 = userId.
  4. Dựng link: 
    https://s.shopee.vn/an_redir?origin_link=<url chuẩn>&affiliate_id=<id>&sub_id=<s1-s2-...>
  5. Khi user click → Shopee trả 301 về trang sản phẩm, tự gắn: utm_source=an_<affiliate_id>, utm_content=<sub_id>, utm_medium=affiliates, uls_trackid=... (phiên tracking) → hoa hồng quy về đúng affiliate + user.
✅ Không có bước nào cần Chrome/cookie/captcha/proxy. Server chỉ gọi mạng khi phải resolve link rút gọn; link sản phẩm chuẩn thì thuần ghép chuỗi.

Logic đọc report (/api/report)

Code: src/shopee.js + src/cookieStore.js.

  • Gọi affiliate.shopee.vn/api/v3/report/list bằng cookie (axios thuần). Lý do dùng cookie: endpoint report không bị kiểm vân tay TLS/captcha như endpoint tạo link, nên chỉ cần cookie hợp lệ là đọc được — không cần trình duyệt.
  • Cookie lưu ở /data/report-cookie.json (volume bền), cập nhật qua /cookie.html (dán cookie hoặc nguyên câu cURL — trang tự tách).
  • sub_id của mỗi đơn nằm ở trường utm_content (chuỗi nối -); /api/report/by-subid tách utm_content để lọc theo user.
  • Cookie hết hạn (~1–2 tuần) → Shopee trả 90309999 → server tự cảnh báo (Telegram/webhook) nhắc cập nhật.
