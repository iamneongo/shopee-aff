Giới thiệu

REST API bao bọc API nội bộ của Shopee Affiliate để tạo affiliate link và lấy báo cáo chuyển đổi. Mọi response đều là JSON với trường ok (true/false).

⚠️ Đây không phải API chính thức của Shopee. Nó hoạt động nhờ cookie/session của bạn và có thể ngừng chạy khi Shopee thay đổi hệ thống.

Kiến trúc bridge

Shopee chống bot bằng chữ ký x-sap-sec dùng một lần, sinh trong trình duyệt. Vì vậy server không thể tự gọi endpoint tạo link (luôn lỗi 90309999). Giải pháp: một Chrome extension làm cầu nối.

client → POST /api/link → API server ──WebSocket(/bridge)──▶ Extension (background)
                                                                │ executeScript → tab Shopee (MAIN world)
        client ◀── shortLink ◀── API server ◀───────────────────┘
Chức năngCách chạy
POST /api/linkQua extension bridge (cần extension + tab Shopee đăng nhập)
GET /api/report*Trực tiếp bằng cookie trong config.json
Xem extension/README.md để cài extension (Load unpacked).

Cài đặt & chạy

npm install
copy config.example.json config.json   # rồi điền cookie/token
npm start                                # http://localhost:3000

Mở http://localhost:3000 để vào trang test, hoặc http://localhost:3000/docs.html cho trang này.

Xác thực

Nếu apiKey trong config.json được đặt (khác rỗng), mọi request tới /api/* phải kèm header:

x-api-key: <apiKey của bạn>

Để trống apiKey nếu không cần bảo vệ (chạy nội bộ).

Endpoints

GET /health

Kiểm tra server sống + liệt kê endpoint.

Response 
{ "ok": true, "service": "shopee-aff-api", "endpoints": [ ... ] }

GET /api/bridge/status

Kiểm tra extension đã kết nối server chưa. Nên gọi trước khi tạo link.

Response 
{ "ok": true, "online": true }   // false = chưa có extension

POST /api/link

Tạo affiliate link từ 1 link Shopee gốc. Chạy qua extension bridge.

Yêu cầu: extension đã kết nối (/api/bridge/status → online:true) và có 1 tab affiliate.shopee.vn đang đăng nhập mở trong Chrome.
Body (JSON)
TrườngKiểuBắt buộcMô tả
originalLinkstring✅Link Shopee cần tạo aff
subIdsobject—{ subId1..subId5 }; bỏ trống → extension dùng mặc định
Ví dụ 
curl -X POST http://localhost:3000/api/link \
  -H "Content-Type: application/json" \
  -d '{"originalLink":"https://s.shopee.vn/xxxxx"}'
Response 
{
  "ok": true,
  "shortLink": "https://s.shopee.vn/4B0Ewn8cl3",
  "longLink": "https://shopee.vn/universal-link/product/...",
  "raw": { ... phản hồi gốc từ Shopee ... }
}
Lỗi thường gặp
errorNghĩa
Extension chưa kết nối…Chưa mở Chrome có extension / server sai port
Chưa mở tab affiliate.shopee.vn…Extension online nhưng không có tab Shopee đăng nhập
Extension không phản hồi kịp (timeout)Trang Shopee treo — thử tải lại tab

GET /api/report

Lấy danh sách đơn trong khoảng thời gian.

Query params
ParamMặc địnhMô tả
days7Số ngày gần nhất
page1Trang
size50Số đơn mỗi trang
Ví dụ 
curl "http://localhost:3000/api/report?days=7&page=1&size=50"
Response 
{ "ok": true, "total": 12, "list": [ { "order_sn": "...", "commission": "...", ... } ] }

GET /api/report/by-subid

Lấy báo cáo rồi lọc các đơn khớp SubID.

Query params
ParamMặc địnhMô tả
subIds—Danh sách SubID, cách nhau dấu phẩy: web,test
days7Số ngày gần nhất
Ví dụ 
curl "http://localhost:3000/api/report/by-subid?subIds=web,test&days=7"
Response 
{ "ok": true, "total": 12, "matchedCount": 3, "subIds": ["web","test"], "matched": [ ... ] }

Xử lý lỗi

Khi lỗi, response có dạng:

{ "ok": false, "error": "mô tả lỗi", "code": 90309999 }
HTTPÝ nghĩa
400Thiếu tham số (vd không có originalLink)
401Sai/thiếu x-api-key
404Sai endpoint
500Lỗi từ Shopee hoặc token hết hạn

Lấy lại token khi hết hạn (lỗi 90309999)

Cookie và các token (x-sap-sec, x-sap-ri, af-ac-enc-*, csrf-token) do trình duyệt sinh ra và sẽ hết hạn.
  1. Mở affiliate.shopee.vn, đăng nhập, mở DevTools → tab Network.
  2. Thực hiện thao tác (tạo link / mở trang report) để thấy request tương ứng.
  3. Copy các header + Cookie mới, dán vào config.json (mục link hoặc report).
  4. Không cần restart — config được đọc lại mỗi request.
