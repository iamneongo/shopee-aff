Giới thiệu

REST API cho hệ thống cashback Shopee affiliate: tạo affiliate link gắn theo từng user (để quy hoa hồng) và lấy báo cáo chuyển đổi. Mọi response là JSON với trường ok: true/false.

⚠️ Dùng API nội bộ Shopee qua session trình duyệt — không phải API chính thức, có thể thay đổi bất cứ lúc nào.

Kiến trúc

Shopee kiểm dấu vân tay TLS post-quantum (X25519MLKEM768) ở endpoint tạo link — Node/curl thuần bị chặn (error 90309999). Giải pháp: dùng Puppeteer điều khiển một Chrome thật (đã đăng nhập) để gọi fetch() bên trong trang, TLS khớp Chrome → tạo link được.

client → POST /api/link
          → Express (server.js) → puppeteerWorker.js
          → page.evaluate(fetch) trong Chrome thật (đã login)
          → Shopee batchCustomLink API
          ← shortLink ←──────────────────────────────────────

Thao tác Chrome chạy tuần tự (queue) — không tạo nhiều link song song được. Mọi lệnh tạo link đều ensureOnApp() trước: tự điều hướng về affiliate.shopee.vn nếu trang bị đổi, và tự giải captcha nếu Chrome bị redirect sang trang verify.

Cashback & SubIds

Shopee cho gắn tối đa 5 SubId vào mỗi link; khi có đơn, báo cáo trả lại đúng các SubId → dùng để quy đơn về từng user.

⚠️ SubId chỉ chấp nhận [a-zA-Z0-9], tối đa 40 ký tự — không dấu gạch dưới, không ký tự đặc biệt. Vi phạm → server trả 400 INVALID_SUBID trước khi gọi Shopee.

Quy ước mặc định (đổi ở config.defaultSubIds):

SubIdÝ nghĩaVí dụ
subId1userId — người nhận cashback (truyền qua trường userId)u12345
subId2Nguồn / nền tảngweb, app
subId3Nhãn / chiến dịchcashback
subId4, subId5Tuỳ ý (mã đơn, click id…)—

Luồng cashback:

  1. User bấm "lấy link" → gọi POST /api/link kèm userId → link gắn subId1 = userId.
  2. User mua hàng qua link đó.
  3. Định kỳ gọi GET /api/report/by-subid?subIds=<userId> → ra đơn + hoa hồng → tính cashback.
💡 Nên cache (userId, originalLink) → shortLink ở DB riêng — link Shopee là vĩnh viễn, lần sau dùng lại khỏi gọi API, giảm tải Chrome và tránh anti-bot.

Xác thực

Nếu config.apiKey (hoặc biến môi trường) khác rỗng, mọi request /api/* phải kèm header:

x-api-key: <apiKey của bạn>

Endpoints

GET /health

Kiểm tra server sống + liệt kê endpoint. Không yêu cầu x-api-key.

{ "ok": true, "service": "shopee-aff-api", "mode": "puppeteer", "endpoints": [ ... ] }

GET /api/worker/status

Trạng thái Chrome worker. Nên kiểm tra trước khi tạo link hàng loạt.

{
  "ok": true, "mode": "puppeteer",
  "online": true,        // = ready && loggedIn
  "ready": true,         // Chrome đã khởi động
  "loggedIn": true,      // đang đăng nhập Shopee
  "headless": false
}

loggedIn:false → cần đăng nhập lại qua noVNC (production) hoặc cửa sổ Chrome bot (local).

GET /api/worker/open-login

Điều hướng Chrome tới affiliate.shopee.vn (hoặc URL tuỳ ý qua ?url=). Dùng khi Chrome đang ở trang lạ hoặc cần khởi động lại session.

curl -H "x-api-key: <key>" "https://shopee-api.apps.neooi.com/api/worker/open-login"
{ "ok": true, "url": "https://affiliate.shopee.vn/offer/custom_link", "loggedIn": true }

GET /api/worker/rotate-proxy

Tự động lấy proxy Việt Nam miễn phí (từ ProxyScrape + GeoNode API), test TCP, rồi khởi động lại Chrome với proxy đó. Chrome tắt ~5–10 giây sau đó mở lại.

Dùng khi IP server bị Shopee bắt captcha liên tục và auto-solve thất bại.

curl -H "x-api-key: <key>" "https://shopee-api.apps.neooi.com/api/worker/rotate-proxy"
Response thành công 
{ "ok": true, "proxy": "http://14.225.240.23:8562", "ready": true, "loggedIn": true, "headless": false }
Response lỗi 
{ "ok": false, "code": "NO_PROXY", "error": "Không tìm thấy proxy VN nào hoạt động từ proxy5.net." }
⚠️ Sau khi đổi proxy, Chrome sẽ cần đăng nhập lại Shopee nếu session bị mất. Kiểm tra loggedIn trong response; nếu false → vào noVNC đăng nhập lại. Proxy miễn phí là datacenter VN — tốt hơn IP nước ngoài nhưng Shopee vẫn có thể bắt captcha; proxy residential cho kết quả tốt hơn.

GET /api/worker/screenshot.png

Trả ảnh chụp màn hình Chrome hiện tại (PNG). Dùng để xem trạng thái từ xa mà không cần mở noVNC.

curl -H "x-api-key: <key>" "https://shopee-api.apps.neooi.com/api/worker/screenshot.png" --output screen.png

Captcha & Auto-solve

✅ Hệ thống tích hợp SadCaptcha — tự động giải Shopee slider captcha, retry tối đa 3 lần với puzzle mới mỗi lần.

Khi Chrome bị redirect sang trang verify/captcha hoặc Shopee trả error 90309999, hệ thống thực hiện vòng lặp:

  1. Nếu đang ở trang "Verification timed out" → tự click Go Back để quay lại trang captcha.
  2. Puppeteer chụp ảnh puzzle background + puzzle piece ngay trong trang.
  3. Gửi lên SadCaptcha API (sadcaptcha.com/api/v1/shopeeSlider) → nhận pixel offset cần kéo.
  4. Kéo slider với chuyển động ease-in-out 35 bước + nhiễu ±2px (trông tự nhiên).
  5. Kiểm tra: puzzle biến mất → giải thành công → retry tạo link.
  6. Nếu thất bại → click nút refresh ↺ để lấy puzzle mới → lặp lại từ bước 2 (tối đa 3 lần).
  7. Sau 3 lần đều thất bại → trả 503 CAPTCHA, gửi thông báo Telegram + ảnh màn hình.

Cấu hình: đặt SADCAPTCHA_API_KEY trong biến môi trường (production: Dokploy Env) hoặc config.sadcaptcha.apiKey.

💡 IP datacenter bị Shopee bắt captcha thường xuyên hơn IP nhà. Khi auto-solve liên tục thất bại, thử GET /api/worker/rotate-proxy để đổi sang IP Việt Nam khác, hoặc cấu hình proxy residential/4G VN vào config.puppeteer.proxy.

Thông báo (Telegram / Webhook)

Server tự bắn thông báo kèm ảnh màn hình khi cần admin can thiệp (captcha auto-solve thất bại, mất đăng nhập).

Cấu hình config.notify 
"notify": {
  "enabled": true,
  "cooldownSec": 300,
  "telegram": { "botToken": "123:ABC", "chatId": "123456789" },
  "webhook": "https://..."
}
Lấy Telegram botToken + chatId
  1. Chat với @BotFather → /newbot → lấy botToken.
  2. Nhắn 1 tin cho bot vừa tạo, mở https://api.telegram.org/bot<token>/getUpdates → lấy chat.id.
  3. Điền vào config.notify.telegram (production: sửa File Mount trong Dokploy → Redeploy).
Kiểm tra 
curl -H "x-api-key: <key>" https://shopee-api.apps.neooi.com/api/notify/test

Bảo trì (login / captcha)

Production (Dokploy)

  1. Đăng nhập lại (loggedIn:false): mở noVNC → nhập VNC password → đăng nhập Shopee trong Chrome đang chạy.
  2. Captcha thủ công: nếu auto-solve thất bại (nhận thông báo Telegram), vào noVNC → tạo 1 link qua giao diện web affiliate.shopee.vn/offer/custom_link → giải captcha → nhận cookie AC_CERT_D → API chạy lại.
  3. Xem trạng thái nhanh: GET /api/worker/screenshot.png — không cần mở noVNC.
  4. Điều hướng Chrome: GET /api/worker/open-login để đưa Chrome về trang affiliate.

Local (Windows)

  1. Chạy start-chrome.bat để mở Chrome bot (cổng 9222, profile C:\shopee-bot-profile).
  2. Đăng nhập Shopee trong cửa sổ đó → chạy npm start.
  3. Nếu bị captcha: vào affiliate.shopee.vn trong Chrome bot, tạo 1 link qua giao diện, giải captcha → API chạy lại.

Session hết hạn

Session Shopee hết hạn sau vài ngày đến 2 tuần. Dấu hiệu: loggedIn:false hoặc nhận thông báo "MẤT ĐĂNG NHẬP". Giải pháp: đăng nhập lại qua noVNC.
