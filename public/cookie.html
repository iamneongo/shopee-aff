🍪 Cập nhật Cookie Report — Shopee Affiliate

Dùng khi báo cáo /api/report báo cookie hết hạn (thường ~1–2 tuần/lần). Lấy cookie: đăng nhập affiliate.shopee.vn → mở trang Báo cáo chuyển đổi → F12 → tab Network → chọn request report/list → Request Headers → copy nguyên chuỗi header Cookie → dán vào ô dưới → Lưu.

Đang kiểm tra trạng thái cookie…
Lưu ý
  • Cookie được lưu trên server (volume bền), không nằm trong repo.
  • API key được nhớ trong trình duyệt này (localStorage) cho tiện, không gửi đi đâu ngoài API của bạn.
  • Khi cookie hết hạn, hệ thống tự gửi cảnh báo (Telegram/webhook nếu đã cấu hình).
